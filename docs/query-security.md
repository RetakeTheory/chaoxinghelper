# 登录安全与多课程队列

## 实施边界

HTTPS 仍是主要传输安全边界。本次额外加密只减少请求正文、日志或请求样本中暴露明文凭据的机会。不是端到端加密：本站必须解密凭据才能向学习通登录，不改变上游协议，也不保存密码。

不能阻止恶意浏览器扩展、XSS、被替换的站点脚本或受控客户端读取输入。若攻击者取得完整请求、同浏览器 Cookie 及同出口访问能力，仍可能抢先使用一次请求；重放防护不能消除这种竞争。客户端验证不证明用户是人类，不保证识别浏览器自动化。

## 一次点击验证

1. `POST /api/query/challenge` 严格检查同源、JSON、浏览器请求头、HTTPS，以及平台提供的风险评分（若可用）。明显的命令行或自动化 User-Agent 被拒绝，但这个粗略信号可以伪造绕过；不信任客户端上报的 webdriver、点击速度、设备指纹或“我是人类”。无 CAPTCHA、无 2FA、无隐藏浏览器指纹采集。
2. 服务端签发三分钟一次性挑战：ECDH P-256 公钥与随机 ID。临时私钥仅在服务端 D1 保存；浏览器不获得服务端私钥。绑定随机 HttpOnly/Secure/SameSite=Strict Cookie、出口 IP、User-Agent 与站点来源，仅保存绑定散列。
3. 浏览器通过 ECDH + HKDF-SHA-256 派生 AES-256-GCM 密钥，用随机 96 位 IV 加密账号密码。来源和挑战 ID 同时参与派生及附加认证数据。
4. `/api/query/login` 原子消费挑战并删除临时私钥，再解密。过期、跨来源、缺失 Cookie、篡改及重复提交均拒绝；不接受明文降级。
5. 仍验证新签发的本站 HttpOnly 会话 Cookie，验证成功才进入看板。未通过时不停止已有后台任务。

挑战按 IP 每十分钟最多 120 次；登录按 IP 每十五分钟最多 60 次；账号跨 IP 每十五分钟最多 6 次。先原子预占，再进行上游请求，避免并发绕过。登录成功不清除 IP/账号窗口。共享出口可能触发限制，应根据实际合法流量调整，不应无限放行。

未使用的过期挑战在每分钟定时任务或后续挑战请求清理；过期后不可解密登录。限流散列超过 24 小时同样清理。无可用边缘风险评分时仍执行本地限流和协议检查，不伪称已启用完整 Bot Management。能执行同样协议且未超限的自动浏览器仍可能通过。

## 可复现实验

`node --experimental-strip-types --test tests/query-login-guard.test.mjs`

全部使用虚构账号和内存数据库，没有截获真实用户、触发上游登录、签到或视频上报。实验覆盖正文不可读、缺 Cookie、变更 IP/UA、密文篡改、过期、并发重放、限流并发与请求超长；同时明确“完整凭据遭窃仍可抢先一次”的限制。

## 一人多课程

网站“加入课程队列”最多排队十门课，当前课程继续。每账号同时只运行一门视频课程，完成扫描及所有未完成视频后转入下一门；未完成视频队列与课程队列均持久化。课程重复添加幂等，重新登录和调度器重建保留队列。暂停不会因加入队列自动恢复，验证码或任务限制不会自动越过到下一门。可移除排队课程；取消挂载清除当前及所有排队课程，签到监听保持原状态。

原有账号并发槽、上游请求预算、扫描节奏及播放经过时间保持不变，没有把课程数直接乘进并发。当前任务不重建、不清空。不处理章节检测、文档资源等非视频节点。

## 常驻与 SSH

Cloudflare Durable Object 已保存调度状态和闹钟；不依赖浏览器长连接。学习通代理仍在本机，通过 Tunnel 接入。SSH 只是远程管理连接，不提供服务器，也不使任务常驻。用户确认没有服务器，因此没有新开 SSH 端口、安装远程访问服务或迁移凭据。

本机既有登录触发任务及 watchdog 保持原样；电脑关机/休眠仍会中断代理。若以后有服务器，应通过 SSH 部署 systemd/容器重启策略，持久化必要状态，配置健康检查、日志轮转和最小权限；不能仅依赖 SSH 终端中的后台进程。
